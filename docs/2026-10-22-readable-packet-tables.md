# TCPView 全局字段对照界面（2026-10-22）

## 范围

仅改 `tcpv_mitm_emitter/app.js` 展示；不改变 DFM、代理、报文规则、解析器、存储、业务动作及筛选规则。并非 Login 特例：GCloud 全部已支持的命令、请求与响应、ACE/TSS 内层记录、独立 TerSafe 子记录及其他普通报文共用表格。

## 展示

- 统一“字段 / 修改前 / 修改后 / 状态”。默认只看变化，可切换全部字段。
- 前后值左右并列，使用弱红/弱绿区分；字段路径和类型为辅助说明，未知含义不命名成已确认协议字段。
- GCloud 按字段号及每层重复序号对应，不按字节偏移或长度对应。重复元素按出现顺序，不宣称业务实体匹配。
- 完整 JSON 按路径对应；整数超出安全范围、内容不完整、非 JSON 等情况保留原始内容，不使用不可靠数值。
- TerSafe 共用子记录入口，复用已定位字段边界；已确认结构不同的正文不强行按原槽位比较。未定位的剩余字节完整保留。
- 普通及未知报文展示长度、候选可读文本、完整内容。候选文本按顺序对应，不冒充已确认字段。
- 移除逐字节变化流水账；不把加密扩散造成的变化数量当作业务字段变化数量。
- 合并重复概要，不再默认展示字符串卡片墙。原始字段树、完整封包、递归解码、资源校验及调试信息可手动展开。
- 没有完整修改前记录时只展示当前内容，不能假造新增/删除或声称发送；部分嵌套解析保留为完整不透明值，不丢未解析尾部。
