## 普通报文展示

- 统一“字段 / 修改前 / 修改后 / 状态”。默认只看变化，可切换全部字段。
- 前后值左右并列，弱红/弱绿区分；字段路径和类型作为辅助说明，未知含义不假装已确认。
- GCloud 按字段号及每层重复序号对应，不按字节偏移或长度对应。重复元素按出现顺序，不宣称业务实体匹配。
- JSON 按稳定路径对应；任一侧不能可靠解析时，两侧都回退原值。超出安全整数范围、不完整内容不作可靠数值。
- 普通未知报文保留长度、候选可读文本和完整内容。候选文本不可对应时明确标注，不误报成协议字段删除。
- 去掉普通报文逐字节变化流水账及重复字符串卡片墙；原始字段树、完整封包和调试信息可手动展开。
